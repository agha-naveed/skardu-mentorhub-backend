# API reference

_Generated by `node scripts/routes.mjs` — 135 routes._

All routes are under the server address and return JSON. Errors are `{ "error": "a sentence a person can read" }`.
Send `Authorization: Bearer <token>` (from `/api/auth/login`) on everything except the **public** routes.

## Live events (Socket.IO)

Connect with `auth: { token }`.

| Event | Direction | Meaning |
|---|---|---|
| `notification:new` | server → app | A notification was created; carries `data.route` |
| `chat:join` / `chat:leave` | app → server | Enter or leave a conversation (checked against enrollment) |
| `chat:message` | server → room | A new message |
| `chat:unread` | server → user | A message arrived while on another screen |
| `chat:ack` | app → server | The message reached this phone (second tick) |
| `chat:read` | app → server | The conversation was looked at (blue ticks) |
| `chat:delivered` / `chat:seen` | server → room | Receipt updates for the sender |
| `chat:typing` | both | Typing indicator (never stored) |
